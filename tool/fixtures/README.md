# Project bundle preflight fixture

`project_bundle_checklist/` is a two-page, offline-readable **development fixture**.
It is not generated by the Agent and is not registered in the app player.

Run from the repository root:

```sh
dart run tool/verify_project_bundle.dart tool/fixtures/project_bundle_checklist
```

The command checks actual bytes, file hashes, the exact file inventory, a
bounded page/action inventory, and the identity plus protocol hash in
`agent.md`. It rejects symbolic links and unexpected files. Run it on a
caller-controlled workspace that is not concurrently being modified; it is
not a hostile-filesystem sandbox or a ZIP extractor.

This initial profile is `maaso.project.preflight.v2`. It uses portable ASCII
paths and fixed-schema canonical JSON, **not general RFC 8785/JCS**. The digest
is namespaced by the profile. It must not be used as the final production
CandidateManifest or as a security, runtime, offline-network, gameplay, or
publication verification receipt.

The runtime protocol currently validates only page/action inventory shape.
Neither a document nor a successful preflight enables Agent control. UI input
on the fixture is temporary, and reopening it does not restore checked items.

When modifying the fixture, first update `agent.protocol.json`, then put its
raw-byte SHA-256 in the JSON front matter of `agent.md`. Finally update the
lengths and SHA-256 entries in `project.json`. The manifest is external to its
own file inventory so hashing does not create a cycle.

# Login doorway artwork and animation

The public entrance is generated by the project-owned
`unity/masso_avatar/Assets/MaasoAvatar/Editor/OpenMaasoLoginDoorwayBuilder.cs`.
Its meshes are Unity cube primitives with project-authored materials and a
built-in `TextMesh` WELCOME label. The geometry uses the shared entry contract's
door dimensions, camera anchors and six ordinary raised panels.

The scene uses the existing `PersistentWorldMapController`, one
`LoginDoorwayRig` / `LoginDoorwaySceneBinding`, and the original
`LoginDoorwayTransitionController`. The prepare, 650 ms opening, 1200 ms entry
and 300 ms framing stages animate that shared door and camera; the existing
free VRM actor is retained in place. Flutter login layout and controls are
unchanged.

The generated source does not import a room FBX, Blender file, baked texture,
licensed room prefab, or the original room poster. The included VRM retains
its separate Pixiv license and provenance.

`login_doorway.png` is the actual Unity prepare-camera crop: the upper 48% of a
900 × 1950 portrait render, yielding a 900 × 936 image. The full transition is
captured through the real command receiver in Editor Play Mode, including its
after-frame acknowledgments. Capture with an installed Metal toolchain:

```sh
OPEN_MAASO_DOORWAY_EVIDENCE=/absolute/local/evidence \
  "$UNITY_EDITOR" -projectPath "$PWD/unity/masso_avatar" \
  -executeMethod Maaso.Avatar.Editor.OpenMaasoLoginDoorwayVerification.BeginCapture \
  -logFile /absolute/local/capture.log
```

Run the visual capture without `-batchmode` or `-nographics`: Unity Editor
batch mode does not resume `WaitForEndOfFrame`, which the production receiver
uses to acknowledge a rendered camera phase. The helper opens Game View and
exits that Editor process after verification. It is not the macOS Maaso app.

`login-doorway.provenance.json` records the Unity version, poster SHA-256,
scene-dependency digest and four successful bridge receipts. The six full
transition frames remain local verification evidence. The reviewed poster hash
is also pinned by `generated-scene-assets.json`; placeholder regeneration must
preserve it.

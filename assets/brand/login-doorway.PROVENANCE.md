# Original Home and login presentation

The original Maaso Home background and login poster are retained byte-for-byte.
The scene uses the original Coastal V4 room, its single shared entrance,
original camera/lighting/depth-of-field settings and original login controller.
Only the character is replaced with the reviewed free VRM and corrected idle.

Room ownership, CC0 texture inputs and exact runtime asset hashes are recorded
in [original-room.PROVENANCE.md](original-room.PROVENANCE.md) and
[original-room-assets.json](original-room-assets.json).
`generated-scene-assets.json` pins the original poster bytes. The placeholder
generator preserves both Home and login artwork.

The earlier generic primitive doorway was an incorrect migration substitute;
it is retired. Visual probes write only local evidence and never overwrite
the original presentation resources. Receiver phases retain the original
650 ms opening, 1200 ms entry and 300 ms framing.
